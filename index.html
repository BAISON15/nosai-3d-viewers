園芸施設共済

園芸施設 3Dビューア

パイプハウス(Ⅱ類)・鉄骨屋根型(Ⅳ類)・雨よけ施設(Ⅵ類)・多目的ネットハウス(Ⅶ類)・ガラス室の5型式。鉄骨屋根型とガラス室は単棟/2連棟/3連棟に対応(谷樋・接続側面を再現)。施設構造部分の色分け、被覆材切替、寸法線表示、部材ハイライトに加え、台風・大雪の被害シミュレーションで損害評価の練習ができます。

農機具 3Dビューア

乗用型トラクタ・乗用型田植機・自脱型/普通型コンバイン・薬剤散布用乗用管理機の5機種。トラクタはロータリー・プラウ・あぜ塗機・ブームスプレーヤなど附属装置15種の着脱に対応(3点リンク/ドローバー接合・PTOシャフトを再現)。オーガ・ブームの格納/展開切替、部材ハイライト付き。

 建物共済

一般住宅 3Dビューア

木造在来工法の一般住宅を平屋/2階建て、切妻/寄棟/片流れ/陸屋根の4屋根形状で切替。軸組・外装(屋根材/外壁材テクスチャ、破風・雨樋・庇・雨戸・パラペット等)・内装まで再現。部位色分け・骨組み表示・内部透過表示・寸法線表示に加え、台風・雹・大雪・水災の被害シミュレーションで損害評価の練習ができます。歩行モードでは実寸スケールで建物の内外を歩き回れます。エコキュート・室外機などの附帯設備、隣家や前面道路といった周辺環境も再現。和風住宅(入母屋)やキューブ型(写真再現)への切替も可能で、農家住宅の瓦屋根・縁側・真壁や、サイディング2色張りの建物を敷地・外構ごと確認できます。

ビューアを開く →
3ビューア共通の機能: 部材を選ぶとオレンジ色にハイライトされ、選択した部材以外は淡色化されるため、柱・梁・筋かいなど形の似た部材の違いを視覚的に確認できます。部材の分け方は「まとめて」と「個別(部材ごと・使用数付き)」を切替でき、部材ごとの色分け表示にも対応。各部材には評価上の着眼点が表示されます。
免責事項: 本モデルは研修・学習用の簡略化されたイメージであり、農林水産省「園芸施設共済評価要領」や各農業共済組合の正式な損害評価基準・様式を完全に再現したものではありません。被害シミュレーションで生成される被害は研修用に自動生成した架空の想定被害であり、実際の被害の分布・程度や損害割合の算定例を示すものではありません。実際の引受評価・損害評価は必ず公式な評価要領・約款・基準に基づいて行ってください。詳細は README を参照してください。
