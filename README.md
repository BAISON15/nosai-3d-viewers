# 農業共済 評価研修用 3Dビューア (Agricultural Insurance Assessment 3D Viewers)

農業共済(NOSAI)の**園芸施設共済**・**建物共済**・**農機具共済**の評価研修を想定した、ブラウザで動くインタラクティブな3Dモデル集です。Three.js製・単一HTMLファイルで、インターネット接続があればダブルクリックで起動できます(インストール不要)。あわせて、米づくりの一年をたどる**3D水稲栽培シミュレーション**を学習コンテンツとして収録しています。

> **技術メモ:** Three.js は最新安定版(0.184.0, r184)を ES Modules + importmap 方式で CDN から読み込みます。

**🔗 デモ(GitHub Pages): https://baison15.github.io/nosai-3d-viewers/**

## 収録コンテンツ(学習用)

評価研修用ビューアとは別に、米づくりの一年をたどる学習用のシミュレーションを収録しています。

| ファイル | 内容 |
|---|---|
| [`rice-sim.html`](rice-sim.html) | **3D水稲栽培シミュレーション 〜一年の米づくり〜。** 田起こし・代かき(春4月) → 田植え(春5月) → 分げつ期・追肥(初夏6月) → 中干し・畦の草刈り(夏7月) → 出穂・カメムシ防除(晩夏8月) → 登熟・落水(初秋9月) → 稲刈り(秋10月)の**7工程**を、3Dの田んぼで1年分体験します。給水/排水で水深を調整しながら各工程の作業(田起こし・代かき・田植え・追肥・中干し・草刈り・防除・間断灌漑・落水・収穫)を進め、**田んぼの水・稲の育ち・雑草/害虫**の状態がメーターで変化します。工程ごとに水深の条件があり、条件から外れた作業(水を張ったままの田起こし・中干し・稲刈り、水が深すぎる状態での田植えなど)は理由を示して止まります。最後に**10アールあたりの玄米収量・お米の等級・田んぼの管理の点数**、工程ごとのふりかえり、その年に出てきた用語(代かき・分げつ・中干し・出穂・斑点米・畦畔の草刈り・登熟・落水・倒伏)の解説が表示されます。 |

> 水を張った田んぼには機械が入れないため、追肥は背負式動力散布機、出穂期の防除はドローン、というように**作業時期に応じた実際の作業方法**を反映しています。

## 主な機能(3ビューア共通)

- **部材ハイライト** — 部材を選ぶとオレンジ色に点滅表示。既定では**選択した部材以外が淡色化**されるため、柱・梁・筋かいなど形の似た部材の違いを視覚的に把握できます(もう一度押すと解除)。
- **部材の分け方切替** — 「まとめて」(関連部材をまとめた区分)と「個別(部材ごと)」を切替。個別モードではモデル上の部材名ごとに分離され、区分の見出しと**使用数**が表示されます(取替割合の考え方の練習に)。
- **部材ごとに色分け** — 部材の種類ごとに色を割り当てて凡例表示。
- **評価の着眼点** — 部材・部位ごとに、評価要領や公開情報に基づく確認ポイントを表示。
- **ドラッグで回転、ホイール/ピンチでズーム**、ラベルの重なりは自動回避。

### 損害評価の練習(園芸施設・建物ビューア)

災害シナリオを選ぶと、モデル上に被害が発生します。被害箇所は赤マーカーで示され、押すとハイライトと評価の着眼点が表示されます。「別の被害パターンを生成」で何度でも異なる被害を作れるため、反復練習に使えます。

- 園芸施設: 台風(風害)・大雪(雪害) — 被覆材の破れ、アーチ・支柱の腰折れ、母屋のまがり、ガラスのひび割れ・脱落、つり線の切断 など
- 建物: 台風・強風/雹/大雪/水災(浸水) — 葺き材のめくれ・飛散、棟の飛散、雹の打痕、雨樋・庇の変形、窓ガラスの破損、天井の雨漏りシミ、外壁の浸水痕(床上/床下浸水で変化) など

> 農機具ビューアには被害シミュレーション機能はありません(部材ハイライト・附属装置の着脱には対応しています)。

### 歩行モード(建物ビューア)

**F**キーまたは画面右下のボタンで、俯瞰(オービット)と歩行モードを切り替えられます。目線の高さ1.6mで建物のまわりを歩き、内部に入って被害箇所や部材を間近で確認できます。

- PC: 画面をクリックして視点操作を開始 / **W A S D** 移動・**Shift** 早歩き・**Q E** 目線の高さ・**Esc** 解除
- スマホ・タブレット: 画面ドラッグで見回し、左下の十字ボタンで移動、右下のボタンで高さ調整
- 「1階の目線」「2階の目線」「見下ろし」のプリセット、壁の当たり判定の有無(すり抜け)を切替可能
- 周辺環境(隣家・道路・塀)は表示/非表示を切替でき、俯瞰時はカメラと建物の間に入った隣家・塀だけを自動で薄く表示して対象建物が隠れないようにします

### 建物モデルの切替(建物ビューア)

| モデル | 内容 |
|---|---|
| 標準(木造在来) | 汎用モデル。階数・屋根形状・屋根材/外壁材の切替、被害シミュレーションが使えます。 |
| 和風住宅(入母屋) | 農家住宅を想定した木造2階建・入母屋屋根・瓦葺きのモデル。下屋、縁側(濡れ縁)、雨戸・戸袋、真壁の化粧柱、破風・懸魚、棟瓦・鬼瓦・隅棟、化粧垂木、切妻の玄関ポーチ、四方を囲う生垣・板塀と門、庭(飛石・松)を再現。内部は畳・広縁・京壁・竿縁天井・襖・障子・床の間・押入まで作り込み。棟の積み直しや土壁の被害など、和風住宅特有の評価着眼点を収録。 |
| キューブ型(写真再現) | 写真を基に再現した木造2階建・窯業系サイディング・緩勾配片流れ屋根のモデル。インナーバルコニー、玄関ポーチ、木目ルーバー、敷地・外構・隣家まで再現。※このモデルでは階数・屋根形状・仕上材の切替と被害シミュレーションは使用できません。寸法は写真からの推定値です。 |

### ライティングの切替(建物ビューア)

右パネルの「ライティング」または**L**キーで、照明を切り替えられます。

| 表示 | 内容 |
|---|---|
| 従来 | 影のない均一な照明。部材の確認に向きます。 |
| 昼 | トーンマッピング(ACES)・空の環境光(ガラスや金物への映り込み)・太陽の影を加えた写実表示(起動時の既定)。 |
| 夕方 | 夕日の低い光と夕焼けの空。室内に明かりが灯り、窓ガラスが暖色に光ります。 |

> 建物ビューアは Three.js のリニア色管理(ColorManagement)を有効にしています。色は指定した値どおりに表示されます。

### 設計情報(建物ビューア・標準モデル)

標準モデルは、間取りと開口部を設計情報(`STD_PLAN`)として持っています。3Dモデルはこのデータから組み立てます。

- **部屋**(rooms): 1階10区画・2階6区画。床の仕上げ(フローリング/畳/タイル/土間)と面積を持ち、夕方の室内灯もこの部屋に配置します。
- **間仕切り**(partitions): 間仕切り壁と室内建具(引戸・襖・開き戸・折れ戸)。
- **家具類**(furniture): 部屋の用途に合わせた家具・家電。LDKにダイニングセット・ソファ・テレビ・冷蔵庫、和室に座卓・座布団・たんす、2階の主寝室にダブルベッド・机、子ども部屋にシングルベッド・机・本棚。窓・建具の前と動線を避けて置いています。NOSAIの建物共済では家具類は建物とは別の共済目的のため、部位区分は「家具類」として建物と分けています(システムキッチン・ユニットバス・押入など造り付けのものは建物に含みます)。
- **開口部**(openings): 外壁の窓・玄関戸。外壁と室内側の仕上げに穴を空け、サッシ枠とガラス(または戸)をはめ込みます。ガラス越しに室内が見えます。柱・筋かいは開口部を避けて割り付け、開口部の上下にまぐさ・窓台を入れます。庇・雨戸の戸袋、被害シミュレーションの窓ガラス割れの位置も、このデータから決まります。

右パネルの「間取り(平面図・面積表)」を開くと、同じデータから描いた**平面図**と**面積表**が表示されます(2階建ては階を切替。「拡大表示」で1階・2階を並べて表示)。

- 平面図: 部屋を床の仕上げ別に色分けし、室名・帖数・面積を記入。間仕切りと室内建具(開き戸は円弧、引戸・襖は建具線)、窓・玄関戸、階段、方位、縮尺を表示します。
- 面積表: 部屋ごとの床面積(㎡・帖)と壁面積(㎡)。壁面積は、壁のある辺の長さ × 天井高から窓・戸の開口を差し引いた値で、クロス張替え面積の目安になります。
- 面積は室内側の仕上げ面(内法)による概算です。1帖=1.62㎡で換算しています。
- 平面図の部屋と面積表の行は連動し、ポインタを乗せると両方が強調されます。

### 寸法の確認(園芸施設・建物ビューア)

間口・奥行・軒高・棟高を、両端にティックの付いた**寸法線**で表示します。寸法名を押すと該当する寸法線がハイライトされます。園芸施設の連棟時は、間口が1棟分を指すことが分かるよう「間口(1棟分)」と表示されます。

## 使い方

### そのまま開く
`viewers/` 内のHTMLファイル、または `rice-sim.html` をダウンロードし、ブラウザで開くだけで動作します(インターネット接続が必要です。Three.jsをCDNから読み込むためです)。

### ローカルで動かす
```bash
git clone https://github.com/baison15/nosai-3d-viewers.git
cd nosai-3d-viewers
# お好みのブラウザで viewers/*.html または rice-sim.html を直接開いてください
```

- 園芸施設共済ビューアの型式・部材・数値は、公開されている評価要領(平成30年5月2日 30経営第367号、以下 改正含む)の記載内容を参考にしていますが、寸法・部材構成は表示用に簡略化・縮小しています。
- 建物共済ビューアの部位区分・着眼点の解説は、一般的な木造建築の部位名称と公開情報に基づく研修用の参考であり、NOSAIの正式な部位区分表・損害割合基準を再現したものではありません。
- 農機具ビューアの機体・作業機の形状は実機と一致しない簡略モデルであり、共済の解説は各NOSAIの公開情報に基づく一般的な枠組みです(**附属装置の加入区分は組合により異なります**)。
- **被害シミュレーションで生成される被害は、研修用に自動生成した架空の想定被害**です。実際の被害の発生確率・分布・程度を再現するものではなく、損害割合の算定例を示すものでもありません。
- **水稲栽培シミュレーション(`rice-sim.html`)は米づくりの流れを学ぶための教材**であり、栽培暦・水管理の基準・生育経過・収量・等級は学習用に簡略化した目安です。地域・品種・栽培方法によって適期や管理方法は異なります。実際の栽培は各地域の栽培暦・指導機関の情報に従ってください。また、農作物共済の損害評価を扱うものではありません。
- 実際の引受評価・損害評価・支払可否の判断は、必ず各農業共済組合等の公式な評価要領・約款・基準に基づいて行ってください。本ツールの内容と齟齬がある場合は公式資料が優先します。
